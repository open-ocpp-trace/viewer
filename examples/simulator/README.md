# Simulator example

Placeholder for deferred work. This example will show
`@open-ocpp-trace/viewer-react` displaying real traffic from the OCPP CP
Simulator, while staying independent of the simulator's logger, UI kit, i18n
setup and application behaviour. It is tracked by
[#10](https://github.com/open-ocpp-trace/viewer/issues/10), with the work in
progress in [#29](https://github.com/open-ocpp-trace/viewer/pull/29). It does
not gate the 0.1.0 release, and no simulator code lives in this repository
until then.
